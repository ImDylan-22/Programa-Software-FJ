## **Software FJ**



#### **Descripción del proyecto**



Software FJ es un sistema desarrollado en Python que permite gestionar clientes, servicios especializados y reservas mediante una interfaz gráfica construida con Tkinter. El proyecto busca organizar las operaciones principales de registro, consulta, confirmación, cancelación y procesamiento de reservas, aplicando programación orientada a objetos y manejo de excepciones.



#### **Objetivo**



Desarrollar un sistema de gestión que permita administrar clientes, servicios y reservas de manera organizada, incorporando validaciones de datos, control de errores y diferentes mecanismos de manejo de excepciones.



#### **Tecnologías utilizadas**



* Python.
* Tkinter.
* Programación orientada a objetos.
* Manejo de excepciones.
* Logging.
* GitHub.



#### **Funcionalidades**



* Registro y consulta de clientes.
* Validación de datos de clientes.
* Registro de servicios especializados.
* Gestión de reservas.
* Confirmación y cancelación de reservas.
* Procesamiento de reservas y cálculo de costos.
* Aplicación de impuestos y descuentos.
* Consulta de información general y estados de las reservas.
* Manejo de excepciones.
* Registro de eventos y errores mediante logging.

#### **Ejecución**



**1|** Instalar Python.

**2|** Descargar o clonar el repositorio.

**3|** Abrir la carpeta del proyecto en Visual Studio Code.

**4|** Ejecutar el archivo main.py.
